Remember the basics:
Ovals (([ ... ])): Mark the BEGIN and END terminals.

Parallelograms ([/ ... /]): Represent input (READ) and output (PRINT) operations.

Diamonds ({ ... }): Represent decision points (WHILE loop validation, IF/ELSE IF branches, and the zero check).

Rectangles ([ ... ]): Show calculation and variable assignment operations.
